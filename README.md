# Rock Paper Scissors Game 🎮

A console-based implementation of the classic Rock Paper Scissors game, built as part of **The Odin Project** foundations curriculum.

## 🚀 About the Project
This project is designed to practice core JavaScript fundamentals, including:
- Functions and scope
- Conditional logic (`if`, `else if`, `else`)
- Loops (`while` loops for input validation, `for` loops for game rounds)
- User interaction via browser `prompt()` and the developer console
- Generating pseudo-random numbers with `Math.random()`

## 💻 How to Play / Run
1. Clone this repository or download the source files (`index.html` and `script.js`).
2. Open `index.html` in any web browser.
3. Open your browser's **Developer Console** (Press `F12` or right-click $\rightarrow$ **Inspect** $\rightarrow$ **Console**)[cite: 1].
4. Follow the prompt instructions to choose **ROCK**, **PAPER**, or **SCISSORS** for 3 rounds.
5. View the round outcomes and final winner score summary directly in the console!
